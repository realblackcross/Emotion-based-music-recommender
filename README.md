# Emotion-based Music Recommender
This project recommends music based on your emotion detected via webcam.
Built with Streamlit and facial emotion recognition.

## Run Locally

Clone the project:

```bash
git clone https://github.com/realblackcross/Emotion-based-music-recommender.git
cd Emotion-based-music-recommender

## Install dependencies

npm install

## Start development server
npm run dev
#or
streamlit run music.py
